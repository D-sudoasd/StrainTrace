# Support and maintenance

Use [GitHub issues](https://github.com/D-sudoasd/StrainTrace/issues) for installation,
usage questions and reproducible defects. Delun Gong is the maintainer; response times
are not guaranteed. For private correspondence use dlgong17s@imr.ac.cn. Do not attach
confidential experimental data to a public issue. Supply a minimal synthetic example
when possible and distinguish a program failure from insufficient image texture.
