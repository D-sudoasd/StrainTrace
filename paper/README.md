# StrainTrace JOSS manuscript

`paper.md` and `paper.bib` are the maintained source. The GitHub Actions workflow
**Draft JOSS PDF** uses Open Journals tooling and publishes `straintrace-joss-paper`.
Select the artifact for the exact candidate commit; artifacts expire, so keep a local
copy with the submission package. The draft has no assigned JOSS DOI or acceptance.

The source date is a preparation date. Before submission, complete the author review
and research-use mapping in [the submission guide](../docs/joss/README.md), use the
actual submission date, rebuild and inspect the PDF. The synthetic verification
suite is documented in [validation](../docs/joss/validation.md).
