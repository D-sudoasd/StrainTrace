# Campaign implementation contract v1

Public package is headless on import. All operations accept a project directory (contains project.json). Paths in artifact records are relative to that directory; raw image paths are absolute, never rewritten in place. JSON is strict and finite; missing numeric values are null.

Project: schema_version=1, kind="straintrace_campaign", project_id, name, roots(alias -> absolute path), acquisitions(list), metadata(dict). Acquisition: acquisition_id, name, relative_path, source_kind, physical_specimen_id(null unless confirmed), dimensions({area_mm2,width_mm,thickness_mm,status,source}), analysis_mode(extensometer/fullfield), image_frames(list), measurement_frames(list), roi(null or proposal), approval(null or record), analysis_config(dict), result(null or stage record), alignment(null or stage record), metadata(dict).

Image frame: frame(integer source/native image counter), native_frame(integer), path(absolute image path), timestamp_unix_s(null or recorded epoch), estimated_timestamp_unix_s(null or derived epoch), time_s(null or relative seconds), timestamp_source/status. Measurement frame: frame(analysis counter), native_cbf_frame, scan_id, scan_id_is_global_fio, same time metadata, optional exposure_start_unix_s/exposure_end_unix_s. No ordinal substitution.

ROI proposal: free_region=[x,y,width,height], exclusions(list rectangles), groups=[{name,roi1:[x,y,w,h],roi2:[x,y,w,h]}], reference_frame, reference_path, reference_sha256, diagnostics, preview_paths, proposal_hash. approval binds proposal_hash + reference_sha256 + reviewer + approved_at + specimen_confirmed=true. Tracking uses fixed reference; campaign means require >=3 accepted gauges, sample SD ddof=1. Unknown source gaps remain missing.

Stage result: status, fingerprint, rows_path(relative JSONL), artifacts(relative paths), checksums(relative -> sha256), provenance, summary. Standard rows include frame, native_dic_frame/reference_frame for DIC results or native_cbf_frame for measured axis, force_N, area_mm2, stress_MPa, engineering_strain, true_strain, valid_gauge_count, strain_status, quality_status and reasons. Preserve additional imported source columns losslessly. alignment rows supersede result rows for delivery, never overwrite imported accepted values.

Worker interfaces:
- roi.propose(acquisition, project_dir, free_region=None) -> proposal; roi.validate_approval(acquisition) -> None or error; roi.approve(acquisition, reviewer, specimen_confirmed) -> approval record. Invalid/changed proposals reject. ROI edits are persisted by workflow, not roi module.
- numerics.analyze(acquisition, project_dir, progress=None, cancel=None) -> stage record; core only numerical engine. numerics.fingerprint(acquisition) -> stage dependency hash.
- adapters.discover(root, adapter="generic", pattern=None, exclude=()) -> list acquisition dictionaries. Root alias and deterministic IDs are assigned by workflow. adapters/desy.py pure parsers with no private paths.
- alignment.align(acquisition, project_dir, load_path, mode="instantaneous", max_gap_s=2.5, time_column="timestamp_unix_s", force_column="force_N") -> stage record. Resample DIC onto explicit measurement axis when provided. Raw and derived clocks must not silently mix. Confirmed area only for new stress.
- delivery.import_keystone(project_dir, source) -> list acquisition dictionaries (copy metadata/accepted tables only, never raw images, preserve IDs and values); delivery.export_project(project_dir, project, output, publish_to=None, timeout_s=60) -> receipt; delivery.verify_package(path) -> report. Import acquisition.result rows must be JSONL and tagged IMPORTED_ACCEPTED.
- workflow.init_project(path,name,roots), load_project(path), scan(path,root_alias,adapter="generic",pattern=None,exclude=()), import_keystone(path,source), propose_rois(path,acquisition_id,free_region=None), approve_rois(path,acquisition_id,reviewer,specimen_confirmed), run(path,acquisition_id=None,progress=None,cancel=None), align(path,acquisition_id,load_path,**kwargs), export(path,output,publish_to=None), verify(path). workflow owns project mutation, locking, stage reuse and checkpoint integrity. CLI and GUI only call workflow.

No edits to ezdic_core required unless a demonstrated core defect. Public docs/examples use synthetic identities and configurable paths. Legacy CLI v1 unchanged.
