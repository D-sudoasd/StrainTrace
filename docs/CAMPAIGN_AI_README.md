# AI 阅读批次项目

1. 项目入口是 project.json；交付包入口是 CURRENT.json 指向的版本与 catalog。不要按文件修改时间选版本。
2. acquisition_id 标识采集批次。physical_specimen_id 未确认时为 null，候选关联不能自动合并试样或共享尺寸。
3. frame、原始图号和 scan 命名空间必须一起阅读，禁止以排序行号重配。image_frames 与 measurement_frames 是不同轴。
4. recorded/estimated 时间不能混为真实采集时间；读取 status、source、时区和曝光窗。未知时间保持缺失，不使用 TIFF mtime。
5. ROI proposal 只是建议。审批必须匹配参考图 SHA 和几何指纹；输入或几何变化后重新审核。不能因为已确认另一批就自动准入当前批。
6. result/status=IMPORTED_ACCEPTED 是旧结果的保留，不是新算法验证。对齐和导出不得覆盖导入的有限值；新追踪结果应有独立来源和版本。
7. 缺失工程应变在 CSV 为空，应力为字面 null；JSON 缺失数值为 null。零应变表示相对参考帧，不能用零替代缺失。
8. 均值需要至少三条有效引伸计；保留单条轨迹、有效条数、样本标准差及质量原因。插值不创造新的独立有效引伸计。
9. 未确认面积、时钟、试样身份和失配不得自动填补。候选数据不得进入正式列；来源冲突保留并显式标记。
10. 优先复用指纹一致且校验通过的阶段。变更只使相关阶段失效；不得清空旧结果后盲目全量重算。部分版本、取消任务和发布失败不成为 CURRENT。

原始实验图像、真实路径和完整科研基线属于本地数据。公开仓库中的案例为合成或脱敏回归，不能据此声称已校准所有材料和相机构图。
