## 已修复的科学和交付问题

- 分数子区中心不再把参考中心取整，避免固定偏移进入位移结果。
- 可选平滑保持仿射位移，并使用共同有限支撑，避免旋转产生虚假 Green–Lagrange 应变或跨越单分量缺失裂缝。
- 点式标距不能跨遮罩洞改选远处测点；固定端点支持失效时保留空值。
- 报告校验检查配置、计划内容及源清单的哈希对应关系。
- 后处理质量与原 DIC 质量分开显示；失效区域不会被原运行的通过状态掩盖。

## 重现

```powershell
py -3.13 -m pytest -q
py -3.13 scripts/validate_agent_upgrade.py --output E:/analysis/new-validation-directory
py -3.13 -m PyInstaller ezDIC.spec --distpath dist/custom-build --workpath build/custom-build
```

使用新的验证输出目录。原始数据、配置、检查点和可搬移报告包应保留；报告内自带 `verify_report.py`，便携版也支持 `ezDIC-cli.exe agent verify-report --report 报告目录`。

边界：当前方法仍为面内二维 DIC；不处理立体三维位移或出平面误差补偿。像素物理标定只支持显式各向同性尺度，时钟关系与截面积不能从图像猜测；没有实测实验不确定度标定。多个独立序列需明确选择，Agent 自然语言目标映射到当前支持的结构化目标。大序列逐帧处理，但本轮没有宣称已经在数万帧实测数据上完成性能验收。
