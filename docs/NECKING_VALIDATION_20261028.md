# 颈缩阶段调查与验证记录（2026-10-28）

## 结论与适用范围

已证实并修复全局仿射初始化对局部搜索半径的错误收缩；这一问题在已知解的局部位移带中造成有效区域丢失。还修复了非正或数值奇异的局部变形映射仍输出有效应变，以及结果色标和质量状态显示的问题。这些结果不证明用户截图的分叉由上述问题造成，也不证明本软件可在颈缩或断裂附近替代 VIC-2D。全场仍使用固定参考、一阶仿射子集；没有增量参考帧更新或三维位移测量。

## 解释截图前必须核对

核对原图及帧身份、参考帧、标定、坐标轴、参考 ROI 和有效 POI 集合、子集/步长、形函数、应变定义、窗口及滤波。对同一帧同时报告各自有效点、共同有效点及共同参考区域上的统计；逐帧有效区域变化可改变面积均值。面积平均和两端点标距应变不是同一种测量。截图不能给出逐点位移、质量、ROI 或参数，也不能把任一软件当作真值。

例如在无剪切的单轴拉伸中，工程伸长应变 0.15 对应 Green–Lagrange 应变 0.16125；含转动和剪切时，无穷小应变也不一定等于材料线工程伸长。图像坐标 x 向右、y 向下，`Exx/Eyy/Exy` 为 Green–Lagrange 张量分量，`exx/eyy/exy` 为无穷小应变，均无量纲。

## 已知真值试验

连续解析纹理通过独立逆变换生成目标图。搜索验证在固定参考、21 px 子集、30 px 步长、18 px 搜索半径下施加平移和局部位移带。RANSAC 内点中位重投影误差并不限制非仿射区域偏离全局运动的幅度。原版把半径缩为 3 px，局部带 5/24 点通过；修复后保留 18 px，24/24 点通过，全场 125/144 → 144/144。原版和新版接受点集合不同，误差统计不可直接视为配对改善；新版接受点的平均位移向量误差约 0.059 px、最大约 0.471 px。均匀仿射对照均为 144/144，平均误差均约 0.000244 px。此例是面内剪切位移带，不是完整颈缩模型；空间异常阈值特意放宽以隔离搜索行为。报告和输入哈希见 [原版](validation/necking_search_baseline_20261028.json)与[最终版](validation/necking_search_final_v4_20261028.json)。

独立拉伸局部化测试使用有解析位移与 Green–Lagrange 应变的面内场。对于窄峰（高斯宽度参数 8 px），25 px 子集、8 px 步长、5 POI 窗口下，中心截面采样点真值 Eyy=0.3192、估计 0.1902；144/144 点通过相关与应变门。15 px 子集、4 px 步长、3 POI 窗口的相邻采样点真值 0.3168、估计 0.2710。两组采样坐标不完全相同，不能将其视为同点配对；更小的支撑并不保证噪声下始终更准确。真实位移直接送入同一应变拟合仍产生峰值损失，因此位移求解和有限应变窗口均影响该工况。已接受点中仍有位移误差大于 0.5 px 的点，质量门不等于测量准确性。脚本和原始基线见 [基准脚本](../benchmarks/necking_validation.py)及[基线数据](../benchmarks/necking_baseline.json)。

最终版的竞争峰筛查在细网格已知解中，清洁和加噪工况各额外拒绝了 1 个原位移误差不超过 0.5 px 的点；两个工况各仍有 11 个接受点的位移误差超过 0.5 px。不同处理之间的误拒和剩余错误见[竞争峰诊断](validation/necking_competing_final_v4_20261028.json)，最终完整局部化结果见[局部化报告](validation/necking_localization_final_v4_20261028.json)。

四次交替试验中，同一核心打开竞争峰检查的中位耗时相对关闭时，局部带、均匀场和细网格分别为 1.015、1.000 和 1.103 倍。负载未受控、算例较小，不能推广到真实序列；完整数据见[计时记录](validation/necking_competing_timing_v4_20261028.json)。

全量回归中发现，既有合成 PNG 辅助函数把三次插值超过 255 的浮点值直接转为 uint8，部分值回绕为暗像素。修复为饱和裁剪后，同一名义平移场的有效点数为原版 49/49、新版 48/49，位移向量 RMSE 分别约 0.03663 和 0.03669 px；原回绕图分别为 42/49 和 36/49。原覆盖门槛未放宽，回绕损坏图另保留压力测试，相关输入哈希和结果见[量化诊断](validation/png_quantization_validation_20261028.json)。这些是图像生成与鲁棒性检查，不是实验测量精度。

`strain_window_px` 是历史名称，实际单位为 POI 数；窗口的中心跨度为 `(window−1)×step` 像素，图像支撑还包含子集大小。对关心的峰值，应比较多个物理尺度、峰值位置、截面、噪声和共同有效区域。减小窗口只能作为分辨率敏感性分析，不能无条件当作更准确。

第 50 和 90 帧共同有效点的最大 u 差分别约 3.45×10⁻⁷ 和 3.85×10⁻⁷ px，最大 Exx 差分别约 2.40×10⁻⁸ 和 2.13×10⁻⁹；后面三帧不能计算共同有效点误差。历史记录显示第 193 帧已断裂。后期全局特征初值失败，本次修复没有改善这组测试的覆盖率。此稀疏 ROI/帧复算没有实验位移真值，也不是与 VIC 的同测量比较；不能据此判定整个序列可用或不可用。单次计时受共享负载影响，不能据此断言速度变化。

## 使用与质量解释

- 全局特征初值仅用于指定局部搜索中心，`search_radius` 现在仍是相对该中心的搜索半径。竞争峰检查只精修最强的一个独立次峰，其整数相关值至少需达到 `zncc_min−0.10`；两解均通过其他门、相距超过 2 px 且精修后 ZNCC 差不超过 0.08 时标为歧义。如果通过初值检查的全局预测附近有一个通过门的备选解，而主解明显偏离预测邻域，也会标记预测冲突；程序不以预测选定真实解。多尺度保留粗层歧义；默认拒绝该点，显式允许歧义时仍标记风险。阈值未经校准，是启发式筛查，并不能发现所有伪匹配，可能带来误拒和额外计算；应检查峰歧义、ZNCC、收敛及邻域一致性。
- 新增 `deformation_jacobian` 和 `strain_fit_dudx/dudy/dvdx/dvdy`，来自应变拟合而非子集仿射参数 `P`。拟合 det(F)≤0 标记 `NONPOSITIVE_JACOBIAN`；0<det(F)≤16ε·max(1, |Fxx Fyy|+|Fxy Fyx|) 标记 `NEAR_SINGULAR_JACOBIAN`。两类应变为 NaN、`strain_valid=false`，位移和诊断保留。该阈值只防浮点舍入，既不是测量不确定度也不是失相关的完整判据。
- 桌面显示最近有结果的帧，并明确标记通过数值质量门、部分结果或状态未知；部分结果用于排查，不能解释为完整有效。较弱但通过相关等门的竞争候选会在界面显示为待核查的软风险，精细层和多尺度层同一 POI 合并计数；精修失败或记录缺失时标记检查未完成。这不是经过标定的错误概率，也不改变有效性。整轮未通过数值质量门但失败归档完整且存在场时，可只读查看部分场，界面标出失败及清单位置并禁用保存。查看逐帧演化请使用已保存的帧结果和现有分析报告，当前手动全场查看器没有完整逐帧导航。
- 质量分数未经过实验校准。历史 v6 AUC 把拒绝点标为坏结果，不能用来证明质量分数识别误差的能力；新 `candidate_accuracy` 仅在有限真值候选上统计，未知拒绝单独计数。
- 已知的重复纹理反例中，真实位移为 (5, 0) px，强噪声使真实候选的精修 ZNCC 约为 0.919，而远处复制纹理的错误候选约为 1.0。仅使用 0.08 质量差阈值的中间版本会接受错误位移约 (22, 17) px，且帧质量门通过；最终版本在全局预测正确的条件下检测到冲突，默认拒绝该点。但当没有全局预测或预测恰好错误地指向 (22, 17) 时，该反例仍接受错误位移且 9/9 点与整帧质量门通过，界面仅提示较弱竞争候选。另一个预测错误的反向例中，规则会拒绝正确点；这不是用预测证明哪一解正确。有限候选检查仍不能排除其他严重误匹配。相关数据见[预测冲突反例](validation/necking_prediction_conflict_v4_20261028.json)，其中一项保留为预期失败测试。
- 自动分析的新计划对试算和正式计算均启用拒绝**已知未收敛**子集，并将设置写入计划和 checkpoint。收敛状态未知的点仍可能通过其他检查，收敛也不保证真实准确；代码身份改变后旧计划需要重新生成，历史结果不改写。core/CLI 的兼容默认仍需显式设置 `quality.reject_nonconverged=true`；桌面默认启用。
- 单相机 2D DIC 无法仅凭单张投影恢复颈缩造成的离面运动、表面曲率和深度变化。离面运动会造成表观尺度变化；需要独立的成像评估或立体/3D 信息。[iDICs 指南](https://www.idics.org/guide/DICGoodPracticesGuide_PrintVersion-V5h-181024.pdf)与 [NIST DIC Challenge 2.0](https://www.nist.gov/publications/dic-challenge-20-developing-images-and-guidelines-evaluating-accuracy-and-resolution-2d)讨论偏差、噪声与空间分辨率。

## 复现

本轮最终工作区以系统 Python 3.11 执行 `py -3.11 -m pytest -q`：657 项通过、4 项跳过、1 项预期失败。预期失败为上述错误预测对准重复散斑的已知漏检，不能计入通过。另有一条 GUI 高 DPI 测试中的 Matplotlib `constrained_layout` 警告；测试本身通过。

```powershell
py -3.11 -m pytest -q tests/test_necking_search.py tests/test_necking_validation.py tests/test_necking_jacobian.py
py -3.11 benchmarks/necking_search_validation.py --output <新报告.json>
py -3.11 benchmarks/necking_validation.py --output <新报告.json>
```

搜索基准的输出拒绝覆盖已有报告。拉伸基准支持 `--core-file` 指向冻结核心。比较版本应固定 Python/依赖、输入和参数，保留文件哈希；性能比较应多次交替运行并控制系统负载。真实数据复算必须只读原图并输出到新目录。

本机 FIO83 复算可用 `benchmarks/real_necking_pilot.py --images <原图目录> --core-file <核心文件> --output <新目录>`，再用同一输入目录和新版核心指定 `--compare-before <基线目录>/report.json` 生成配对结果。脚本会检查输入哈希、参数和运行环境，拒绝覆盖已有输出。
