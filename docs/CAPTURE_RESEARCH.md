## Dependencies and redistribution

- OpenCV, NumPy and Pillow are existing StrainTrace dependencies. The optional `cv2-enumerate-cameras` distribution retains its MIT license and Yu He copyright.
- The pypylon Python binding and the Basler runtime it loads have separate terms. Install through the official wheel and applicable vendor runtime. Basler SDK binaries are excluded from the generic portable build. [pypylon license](https://github.com/basler/pypylon/blob/d58e305697281e4a5590cd0e5424c3da5280fade/LICENSE) · [pylon runtime distribution](https://docs.baslerweb.com/pylonapi/cpp/pylon_advanced_topics)
- Harvesters uses the separately packaged `genicam` binding and a producer installed by the operator. CTI files are native libraries, with independent vendor redistribution terms. The portable build contains no vendor CTI or GenICam runtime.
- FLIR/Teledyne Spinnaker and Allied Vision Vimba X document GenTL producer installations. Hikrobot MVS documents separate CTIs by interface and architecture. Daheng's MERCURY2 USB3 Vision manual documents Galaxy's GenTL interface. Each Capture deployment still requires the matching 64-bit producer and a test with the intended camera. [FLIR Spinnaker GenTL guide](https://softwareservices.flir.com/Spinnaker/4.4/guides/genicam-gentl.html) · [Allied Vision transport layer manual](https://docs.alliedvision.com/vimba_x/sdkManual.html#tl-activation-and-deactivation) · [Hikrobot MVS 10GigE manual](https://www.hikrobotics.com/cn2/source/vision/document/2023/8/11/%E6%B5%B7%E5%BA%B7%E6%9C%BA%E5%99%A8%E4%BA%BA10GigE%E9%87%87%E9%9B%86%E5%8D%A1%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8CV1.0.0.pdf) · [Daheng MERCURY2 manual](https://dahengimaging.com/downloads/MERCURY2%20USB3%20Vision%20Cameras%20User%20Manual_V2.0.4.pdf)
